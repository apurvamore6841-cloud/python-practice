# Python Coding Assignment – Intern 1

## 📌 Project Overview

This project contains 15 Python coding exercises based on **Modules 1 and 2**, using the theme of **Retail Sales**.

The assignment focuses on Python fundamentals, variables, data types, operators, and data structures.

## 🎯 Objectives

* Understand Python basics and syntax.
* Practice variables, user input, and type conversion.
* Perform arithmetic and logical operations.
* Work with lists, tuples, sets, and dictionaries.
* Understand indexing, slicing, and loops.
* Solve basic real-world retail sales problems.

## ▶️ How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the required Python file.
4. Run the following command in the terminal:

```bash
python q1.py
```

Replace `q1.py` with the filename you want to execute, such as `q2.py` or `q15.py`.
